# Практическая работа 01: Фабрика криптозомби

Смарт-контракт `ZombieFactory` на Solidity ^0.8.20 и автоматические тесты на Foundry (Forge).

## Структура

- `src/ZombieFactory.sol` — контракт
- `test/ZombieFactory.t.sol` — тесты
- `test-output.txt` — результат `forge test`
- `ANSWER.md` — ответ на контрольный вопрос

## Запуск

```bash
forge build
forge test -vv
```
## Контрольный вопрос

**Почему вычисление ДНК не является безопасной случайностью?**

Формула `keccak256(abi.encodePacked(msg.sender, name)) % 10**16` полностью детерминирована: адрес отправителя и имя известны всем, поэтому любой может заранее посчитать результат и даже подобрать имя под нужную ДНК. Источника непредсказуемой энтропии здесь нет, а состояние и входные данные в блокчейне публичны, поэтому для розыгрышей и наград такой способ использовать нельзя (нужны, например, commit-reveal или оракул случайности вроде Chainlink VRF).
